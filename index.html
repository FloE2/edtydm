Périodes de l'année (cycles) — dates de début / fin · le nombre de séances est calculé pour la zone C
Séances comptées d'après le calendrier officiel zone C 2026‑2027 (vacances de Toussaint, Noël, hiver, printemps, été) et les jours fériés en semaine : 11 nov., lundi de Pâques (29 mars), Ascension (6 mai) + pont du 7 mai, lundi de Pentecôte (17 mai). Le lundi de Pentecôte est compté chômé — décochez‑le dans le code si votre établissement travaille ce jour.

Réserve de classes — glissez une classe dans une colonne (ou cliquez la classe puis une case)

Association Sportive — Mercredi

3 créneaux d'1 h, de 12 h 30 à 15 h 30.

Deux colonnes par jour = vos deux titulaires (bleu = Ens. 1, violet = Ens. 2) ; quand les deux ont cours en même temps, les classes sont côte à côte. Chaque créneau est découpé en 4 lignes P1 → P4 (les cycles de l'année) : tapez l'activité, le nombre de séances (calculé pour la zone C, vacances et fériés déduits) s'affiche à côté, puis cliquez le bouton de droite pour le lieu (la couleur). Le bouton co ajoute la co-animation TZR. Glissez une carte sur une autre case pour permuter deux classes. Données enregistrées dans le navigateur ; déposez index.html sur GitHub Pages.
