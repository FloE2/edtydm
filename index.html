Association Sportive — Mercredi

3 créneaux d'1 h, de 12 h 30 à 15 h 30.

Deux colonnes par jour = vos deux titulaires (bleu = Ens. 1, violet = Ens. 2) ; quand les deux ont cours en même temps, les classes sont côte à côte. Chaque créneau est découpé en 4 lignes P1 → P4 (les cycles de l'année) : tapez l'activité, cliquez la ligne pour changer le lieu (la couleur). Le bouton co ajoute la co-animation TZR. Glissez une carte sur une autre case pour permuter deux classes. Données enregistrées dans le navigateur ; déposez index.html sur GitHub Pages.
